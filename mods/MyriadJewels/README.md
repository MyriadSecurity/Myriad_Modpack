# MyriadJewels

Thunderstore BepInEx plugin for the Myriad modpack. Adds seven custom Jewelcrafting stones with tiered powers, synergies, and biome spawns.

Requires **Jewelcrafting** (Smoothbrain).

Full stone and synergy reference: [MyriadJewels source README](https://github.com/MyriadSecurity/Myriad_Modpack/blob/main/src/MyriadJewels/README.md).

Install **Myriad Modpack** for the full curated experience, or install this mod alone if you only want the stones.
