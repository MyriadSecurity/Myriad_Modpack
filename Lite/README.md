# Myriad Lite

Vanilla+ Valheim modpack for dedicated servers and all clients.

- Shared QoL (stacks, craft-from-chests, sleep, paths, barrels, etc.)
- StarLevelSystem — distance stars, location resets, tuned raids
- EpicLoot — enchanting table only (materials loot, no Adventure Mode)
- Homestead — blueprints / templates

Optional client-only extras: **Lite Client Mods** (separate package).

## Install

1. Install with [r2modman](https://thunderstore.io/c/valheim/p/ebkr/r2modman/) on the **server and every client**.
2. Prefer a **fresh world**.
