# MyriadJewels

Seven custom Jewelcrafting stones for the Myriad modpack (Howlite, Carnelian, Bloodstone, Pyrite, Hematite, Tourmaline, Moss Agate).

Requires **Jewelcrafting** (Smoothbrain). Configured in the embedded `MyriadJewels.yaml`.

Install with **Myriad Modpack**, or alone if you only want the stones.
