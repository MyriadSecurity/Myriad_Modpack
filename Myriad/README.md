# Myriad

Vanilla+ Valheim rebuilt around Balrond's Amazing Nature, Arsenal Reborn, and Monster Mayehm — homestead, combat styles, Runeforging, and Jewelcrafting.

**Requires a fresh world** (and preferably a new character).

## Install

1. Install with [r2modman](https://thunderstore.io/c/valheim/p/ebkr/r2modman/) on the **server and every client**.
2. MyriadJewels installs automatically as a dependency.
3. Launch once, then start a **new world**.
